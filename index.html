关于项目

OpenClaw 是什么？

不是聊天机器人。是真正能动手干活的 AI 数字分身——运行在你的设备上，通过消息 App 接收指令，自主执行复杂任务。

🦞
本地优先 持久记忆 主动行动 MIT 开源 多模型路由 社区驱动

OpenClaw（原名 Clawdbot / Moltbot）由奥地利工程师 Peter Steinberger 开发，2025年末在 GitHub 发布，4个月内星标突破 25 万，正式超越 React 与 Linux，成为 GitHub 历史上获星最快的开源项目。

创始人加入 OpenAI 后，项目移交给开源基金会永续运营，真正实现"不受单一商业公司控制"。

Clawdbot 阶段

基础任务自动化功能初步实现，本地文件 + 消息 App 联动

Moltbot 阶段

完成商标合规改造，强化多模型路由，Skills 生态初具雏形

OpenClaw 正式命名 · 2026

模块化架构确立，QQ 原生接入，DeepSeek / Qwen 全面适配，25万 GitHub Stars

核心优势

为什么选择 OpenClaw？

01 / 隐私主权

数据永不离开你的设备

本地部署，所有记忆、文档、对话全部锁在你自己的硬件里。无需将隐私上传到中心化云端，真正掌控属于你的数据主权。

02 / 模型自由

超过 20 家 AI 提供商随心切换

OpenAI、Anthropic Claude、DeepSeek、Qwen、Kimi……多模型 Failover 确保稳定，根据任务自动选择最优、最经济的模型。

03 / 技能无限

Skills 生态，能力几乎没有上限

每个 Skill 是一个功能模块，社区已贡献海量插件。一键安装，热重载。开发者可用 Python 脚本接入任何现实系统。

04 / 真正行动

从 Copilot 到 Autopilot

过去 AI 是副驾驶，你在开车它在旁边看地图。OpenClaw 是自动驾驶——你说目的地，它自己握住方向盘把你送到。

05 / 主动执行

7×24 小时后台运行

心跳机制 + Cron 排程，不需要你每次主动发指令。它会在你睡觉时继续干活，早上起来任务已经全部完成。

06 / 多智能体

AI 团队协作，分工完成复杂项目

一个任务可由多个 Agent 分工处理，支持 MCP 和 ACP 协议，与专业领域 AI（如代码 Agent）强强联合，双向协作。
